# Tools and tests

Valid after: phase 3 (PR #10), `main` `1bbc40d`, verified 2026-10-15; the `validate-story` line updated in phase 4.1 (branch `overhaul/phase-4-evidence`). Details, options and cost notes: [`../../tools/README.md`](../../tools/README.md).

- `node tools/smoke.mjs` (32 scenarios; it expects the boot header `FSOC-BIOS v3.1.4`, ~4 min in parallel, at most `--jobs` (default 14) at once): both trust routes, abort at every stage, trace expiry, reduced and quiet motion, audio cues and no AudioContext before the click, developer routes, and (phase 4b.1) that the CASE FILE button is hidden until the story mentions the case file (both routes, skipped intro, reduced motion, developer jump), and (phase 4) the hacking commands, the board dialog (wide and phone), the keyboard-only board run and lost evidence. Two scenarios were flaky once in a parallel run (see tools/README.md). The timing scenarios run against a `constants.js` served with a 120 s window after the trust choice (the shipped value is 300 s, so a real wait would take minutes; `TEST_WINDOW` in `tools/smoke.mjs`); one scenario (`shippedWindow`) checks the real value. It cannot judge looks or sound.
- `node tools/transcript.mjs --out=<dir>` / `--diff=<a>,<b>`: records the terminal text of four scripted playthroughs (reduced motion) and compares two recordings; used to prove a refactor kept the story text.
- `node tools/validate-story.mjs`: self-test of the narrative engine, then validation and dry runs of the story data (targets, cues, scenes, fields, developer routes), then the evidence data (schema, ids, reachability, 17 mutation self-tests, every `discover` reference in the code), the case file state machine (45 checks) and the hacking commands (31 checks with a fake clock; phase 4.3). No browser needed, runs in about a second.
- `node tools/audio-lint.mjs`: renders every cue and bed offline, checks NaN, silence, peak, headroom, crossfade clicks, trace modes and trace-sound logic (waits for the trace to expire by polling, no fixed sleep).
- `bash tools/check-fonts.sh`: no font-size below 11px (`--all` also includes `.developer-*`; `.case-*` is checked since phase 4.5).
- `node tools/contrast.mjs`: WCAG contrast calculator and CSS audit.
- Owner tests on the preview: `../overhaul/owner-test-checklist.md`.
